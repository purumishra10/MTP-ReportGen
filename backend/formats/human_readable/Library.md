# Library Daily Report Format

## Structure

### 1. Staff Attendance
- **Columns**: On Roll, Absent with Leave, Absent Without Leave, Present, Remarks

### 2. Infrastructure Issues or Maintenance
- **Columns**: S.No., Description, Reported On, Attended On, Completed on, Remarks

### 3. Staff Joined / Left
- **Columns**: S.No, Name, Designation, Date, Remarks

### 4. Library Services or Transactions
- **Columns**: S. no., Particulars, No’s
