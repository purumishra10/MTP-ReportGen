# MTP_ReportGen

This repository contains the code for the MTP_ReportGen project, including both backend and frontend components.

## Project Structure
- `backend/`: Contains the Flask server, database setup, and parsing logic.
- `frontend/`: Contains the HTML, CSS, and JS files for the user interface.
- `Sample_DRs/`: Contains sample Word documents used for Report Generation testing.
- `experiments/`: Standalone scripts for testing data extraction with `python-docx`.

## Setup
1. Clone the repository.
2. Create a virtual environment: `python -m venv venv`
3. Activate the virtual environment:
   - Windows: `venv\Scripts\activate`
   - Linux/Mac: `source venv/bin/activate`
4. Install dependencies: `pip install -r requirements.txt`
